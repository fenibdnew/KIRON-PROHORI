2. User-Mode Real-Time File Guard

Monitors Downloads, Temp, and Windows Startup directories for newly created executables and suspicious modifications without installing kernel drivers.

Monitors Microsoft Defender and Windows Firewall status via read-only WMI queries. Never disables or modifies Windows security settings.

STEP-BY-STEP SETUP

Installation, Browser Extension & Safe Uninstall Guide

  1. Verify SHA-256 Checksum: Download KIRON-PROHORI-Setup-x64.exe and SHA256SUMS.txt from GitHub Releases and run Get-FileHash .\KIRON-PROHORI-Setup-x64.exe -Algorithm SHA256 in PowerShell.
  2. Run Installer with UAC Elevation: Approve the Windows Administrator prompt, choose your installation directory (C:\Program Files\KIRON PROHORI), and select optional desktop/startup tasks.
  3. Windows Background Service: The installer configures KironProhoriSecurityService with delayed auto-start and automatic crash recovery.
  4. Enable Chrome/Edge Browser Extension (User-Consented): Open chrome://extensions or edge://extensions, click Load unpacked, select C:\Program Files\KIRON PROHORI\browser-extension, and run register-native-host.ps1 -ExtensionId <ID>.
  5. Safe Uninstall: Uninstalling via Windows Settings stops the background service, deletes only application-owned files, and asks your permission before keeping or removing your Quarantine Vault.
HARDWARE & OS SPECIFICATIONS

System Requirements

  • Operating System: Windows 10 x64 (Version 2004 / Build 19041 or newer) or Windows 11 x64 (21H2, 22H2, 23H2, 24H2).
  • Processor: 64-bit (x64 / AMD64) dual-core processor or better.
  • Memory (RAM): 2 GB minimum (4 GB+ recommended; scanner runs at BelowNormal CPU priority).
  • Disk Space: ~150 MB free disk space for self-contained .NET 8.0 win-x64 runtime, service, and local quarantine vault.
  • Supported Browsers: Google Chrome (v114+ Manifest V3) and Microsoft Edge (v114+ Manifest V3).
  • Coexistence: Fully compatible with Microsoft Defender Antivirus and Windows Firewall.
